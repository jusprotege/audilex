# AudiLex — Transcritor de Audiências

Downloads oficiais do **AudiLex**, programa para Windows que transcreve gravações de audiência em termo Word,
com marcação de tempo e separação de falantes. Todo o processamento é feito no próprio computador.

- Site: https://audilex.ia.br
- Baixar: veja a seção [Releases](../../releases/latest)
- Contato: franciscofernandes@hotmail.com

Este repositório contém apenas os arquivos de instalação. O AudiLex é software proprietário, licenciado por
AudiLex.ia; o uso está sujeito aos Termos de Licença de Uso que acompanham o programa.
